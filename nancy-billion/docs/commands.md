# Nancy Commands Reference

Slash commands can be typed in chat or invoked by voice when supported.

- `/status` — Show current system status summary and online agent count.
- `/skills` — Open Skills and view attached agents.
- `/memory` — Open memory, session history, and recalled facts.
- `/agents` — Open agent command and specialist roster.
- `/terminal` — Open Command Layer terminal and runtime control.
- `/new` — Start a fresh session or chat.
- `/help` — Show this command reference.

Navigation shortcuts work in most panels:
`overview`, `core`, `agents`, `system`, `kanban`, `news`, `channels`, `instances`, `sessions`, `cron`, `skills`, `models`, `config`, `keys`, `usage`, `profiles`, `pairing`, `plugins`, `mcp`, `webhooks`, `docs`.

For action chains, ask in plain text and Nancy routes through available agents.
