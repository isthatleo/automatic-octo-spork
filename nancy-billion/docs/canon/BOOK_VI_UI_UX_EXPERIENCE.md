# CHAPTER 24

# THE DESIGN LAW

Every visual decision must answer:

Does this make intelligence easier to understand?

Does this reduce cognitive load?

Does this communicate state?

Does this improve trust?

Does this make the user think more clearly?

If the answer is no—

Remove it.

Beauty follows clarity.

Never the reverse.
